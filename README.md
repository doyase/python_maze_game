# 🏁 Python 迷路ゲーム

## 🔹 概要
このプロジェクトは、C言語で作成した迷路ゲームをPythonに移植したものです。  
プレイヤーは迷路の中を移動し、ゴールを目指します！🏆

## 🎮 ゲームの特徴
- ランダム生成された迷路を探索！
- キーボード操作で自由に移動可能
- ゴールまでの最短経路を見つけよう！

## 📌 必要な環境
- **Python 3.8以上推奨**
- 追加のライブラリは不要（標準ライブラリのみ）

## 🚀 インストール & 実行方法
```bash
# リポジトリをクローン
git clone https://github.com/doyase/python_maze_game.git
cd python_maze_game

# ゲームを実行
python maze.py
📝 操作方法
W = 上へ移動
S = 下へ移動
A = 左へ移動
D = 右へ移動
Q = ゲーム終了
